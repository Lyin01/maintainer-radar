# Roadmap

## 0.1 Public MVP

- Local JSON snapshot analysis.
- Issue priority scoring.
- Pull request risk scoring.
- Release readiness summary.
- Codex brief export.
- CI, security policy, templates, and contribution docs.

## 0.2 Maintainer Integrations

- GraphQL-based review decision and CI check ingestion.
- `gh` extension wrapper for maintainers who already use GitHub CLI.
- Configurable label taxonomy per repository.
- Markdown comments suitable for manual PR review notes.

## 0.3 Safety And Scale

- Optional OpenAI-powered issue clustering behind explicit opt-in.
- Redaction checks before any AI prompt is created.
- Dependency and CodeQL alert import.
- Maintainer workload trend reports.

## 1.0 Stable Maintainer Workflows

- Stable snapshot schema.
- Versioned rules engine.
- Release note drafting from merged PRs.
- Public benchmark snapshots from consenting open-source projects.
- Documentation for maintainer teams adopting the tool across multiple repos.
